# OpenDAW

Бесплатная цифровая звуковая рабочая станция для Windows.

[Сайт OpenDAW — попробуй ритм в браузере](https://kyouki-ai.github.io/OpenDAW/)

Создавать ритмы, писать мелодии и собирать треки в одном понятном рабочем пространстве —
с этой целью разрабатывается OpenDAW. Тёмный интерфейс Ember сочетает тёплый графит,
янтарные акценты и спокойные зелёные оттенки.

![OpenDAW](docs/screenshots/native-shell.png)

## Возможности

- Шаговый секвенсор для ударных и ритмических паттернов.
- Piano roll: ноты, длительности, velocity, выделение и дублирование.
- Аранжировка из паттернов: перемещение, повторение и зацикливание.
- Встроенные ударные, синусоидальный и треугольный синтезаторы.
- Микшер: громкость, панорама, mute/solo, low-pass и индикаторы уровней.
- Сохранение проектов с резервной копией, восстановление сессии, undo/redo и экспорт стерео WAV.

## Состояние проекта

OpenDAW находится на раннем этапе разработки. Прототип уже позволяет создавать
паттерны, воспроизводить аранжировку и сохранять результат. Запись аудио, VST3
и сложная автоматизация запланированы для следующих версий.
