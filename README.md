# OpenDAW

Бесплатная цифровая звуковая рабочая станция для Windows.

Создавать ритмы, писать мелодии и собирать треки в одном понятном рабочем пространстве —
с этой целью разрабатывается OpenDAW. Тёмный интерфейс Ember сочетает тёплый графит,
янтарные акценты и спокойные зелёные оттенки.

![OpenDAW](docs/screenshots/native-shell.png)

## Возможности

В разработке:

- Шаговый секвенсор для ударных и ритмических паттернов.
- Piano roll для мелодий и аккордов.
- Аранжировка из паттернов и аудиоклипов.
- Встроенные инструменты и эффекты.
- Микшер, сохранение проектов и экспорт WAV.

## Состояние проекта

OpenDAW находится на раннем этапе разработки. Первый прототип включает рабочее окно,
транспортную панель, настройку темпа и переключение тем. Звуковой движок и музыкальные
редакторы находятся в разработке.
