# Разработка OpenDAW

C++20, CMake 3.22+, JUCE 8.0.12, Windows 10/11 x64.
Для сборки нужны Visual Studio 2022 C++ Build Tools и Windows SDK.
Версия JUCE закреплена контрольной суммой; исходники загружаются при первой конфигурации.

```powershell
.\scripts\build.ps1 -Configuration Debug
.\scripts\build.ps1 -Configuration Release
```

Скрипт находит CMake в Visual Studio, собирает проект и запускает CTest.
После сборки: `Запустить OpenDAW.cmd` в корне проекта.
Для работы без сети можно указать `-DOPENDAW_JUCE_PATH=<JUCE 8.0.12>` при конфигурации CMake.
Отдельная проверка ядра без JUCE: `.\scripts\build.ps1 -CoreOnly`.

## Проверки

Unit-тесты проверяют модель и музыкальное время. GUI smoke открывает окно, проверяет
транспорт, темп, темы и геометрию; сохраняет рендер в `build/windows/screenshots/`.
Тесты рендера компонентов не заменяют проверку физического аудиоустройства и мониторов HiDPI.

## Правила

Форматирование — `.clang-format`. Изменения оформляются небольшими законченными шагами с подходящими тестами.
В audio callback запрещены аллокации, mutex, файловый I/O и уничтожение крупных состояний.
Бинарники, зависимости сборки и секреты в git не включаются.
