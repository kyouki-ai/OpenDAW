# Разработка OpenDAW

C++20, CMake 3.22+, JUCE 8.0.12, Windows 10/11 x64.
Для сборки нужны Visual Studio 2022 C++ Build Tools и Windows SDK.
Версия JUCE закреплена контрольной суммой; исходники загружаются при первой конфигурации.

```powershell
.\scripts\build.ps1 -Configuration Debug
.\scripts\build.ps1 -Configuration Release
```

Скрипт находит CMake в Visual Studio, собирает проект и запускает CTest.
После сборки: `Запустить OpenDAW.cmd` в корне проекта.
Для работы без сети можно указать `-DOPENDAW_JUCE_PATH=<JUCE 8.0.12>` при конфигурации CMake.
Отдельная проверка ядра без JUCE: `.\scripts\build.ps1 -CoreOnly`.

## Проверки

Unit-тесты проверяют модель, музыкальное время, scheduler, loop, mute/pan, отсутствие
operator-new в callback и детерминированность рендера при разных размерах блока.
Экспорт проверяется по заголовку WAV, размеру, отмене и совпадению PCM с движком.
GUI smoke проверяет редактирование, транспорт, темы, undo/redo, сохранение/загрузку,
повреждённые файлы и геометрию; сохраняет рендер в `build/windows/screenshots/`.
Тесты рендера компонентов не заменяют проверку физического аудиоустройства и мониторов HiDPI.

Необязательная проверка устройства: `OpenDAW.exe --device-smoke --report <absolute-report-path>`.
Она открывает output без входов, подтверждает callback и тишину, затем закрывает приложение.
Обычный CTest не открывает аудиоустройство.
Smoke-процессы рендерят компоненты в скрытом окне, чтобы не перекрывать другие приложения.
`demo_export` запускает `OpenDAW --render-demo <path> --report <path>` без устройства
и сохраняет `build/windows/demo.wav` для прослушивания результата движка.

## Правила

Форматирование — `.clang-format`. Изменения оформляются небольшими законченными шагами с подходящими тестами.
В audio callback запрещены аллокации, mutex, файловый I/O и уничтожение крупных состояний.
Бинарники, зависимости сборки и секреты в git не включаются.
Источники и условия использования зависимостей: [лицензии](docs/licenses.md).
Текущая структура: [архитектура](docs/architecture.md), [дизайн-система](docs/design-system.md).
