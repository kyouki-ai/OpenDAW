# GitHub и ежедневная работа

Решение владельца от 2026-10-18: разместить OpenDAW в аккаунте kyouki-ai,
делать минимум одно настоящее изменение с коммитом в день; репозиторий публичный для преподавателя.
Целевой адрес: https://github.com/kyouki-ai/OpenDAW.

Для ежедневной разработки создана активная задача Codex «OpenDAW: ежедневная разработка и коммит»
в текущем чате: каждый день в 19:00 по Asia/Yekaterinburg. Это задача разработки,
а не скрипт, который меняет дату/файл ради искусственной активности.
Она выбирает следующий небольшой шаг плана, проверяет его, обновляет дневник и делает commit/push.
При блокере сообщает причину; успешная отправка должна подтверждаться remote hash.

Локальная задача требует включённого компьютера, работающего Codex, доступа к файлам и GitHub.
Расписание не гарантирует коммит при выключенном ПК, недоступной авторизации, лимитах или провале проверки.
Пропуски не исправляются поддельными датами. Дополнительные ручные проверенные коммиты разрешены.

Проверка преподавателем: открыть публичную вкладку Commits основной ветки;
изменение видно по hash, дате, diff и результату CI. Зелёные клетки профиля не заменяют историю проекта.
Точное учебное требование (дата commit/push, ветка, срок) пока не предоставлено.

Обычный процесс:

1. Прочитать план и дневник, проверить status/log/remote.
2. Выбрать полезный маленький результат, реализовать и проверить.
3. Просмотреть staged diff: без .tools/build/секретов/бинарников.
4. Commit с ясным сообщением, обычный push в основную ветку, проверка remote hash и CI.
5. Записать фактические результаты и дать ссылку на коммит.

Никогда не переписывать чужие изменения, не делать force push и не отмечать провалившиеся тесты успешными.
