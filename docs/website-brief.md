# Сайт приложения — следующий продуктовый этап

Запрос владельца 2026-10-18: «сайт приложению тоже потом сделай», «гениальный красивый»,
«НЕ НЕЙРОСЛОП», с анимациями и переходами. Создать после рабочей версии приложения;
сейчас сайт не разрабатывается и не опубликован.

Визуальная связь с выбранным C / Ember / Sand: тёплый графит, янтарь, шалфей,
авторский волновой знак, точная типографика. Сайт получает собственную редакционную композицию,
а не растянутый скриншот приложения и не универсальный шаблон.

Идея: посетитель видит, как рождается короткая музыкальная фраза — шаги становятся нотами,
ноты складываются в arrangement, камера/масштаб спокойно перемещаются к реальному UI.
Демонстрация интерактивная; звук запускается только явным действием посетителя.
Использовать фактические возможности приложения и собственные звуковые примеры.
Реальные скриншоты и доступная сборка заменяют выдуманные рекламные обещания.

Motion: переходы сохраняют пространственную связь между элементами, темп и playhead связывают сцены.
Не делать scroll hijacking, перегруженные 3D-сцены и непрерывный full-screen рендер без пользы.
Учесть reduced-motion, клавиатуру, мобильные устройства, читаемость и скорость загрузки.
Нет случайных градиентов, бесконечных одинаковых карточек, stock AI illustrations и липовых отзывов.

Перед реализацией: контент, оригинальный storyboard, проверка реальных screenshots и release URL.
Затем implementation, browser QA, мобильная компоновка, запись переходов/скриншоты.
Публикация только после прямого указания владельца; VPS с VPN не используется.
