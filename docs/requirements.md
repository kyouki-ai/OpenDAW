# Требования и границы

Цель MVP: Windows x64, устойчивый звук, synth/sampler, шаги, piano roll, playlist,
gain/pan/mute/solo, сохранение/открытие, offline WAV, основные undo/redo. Полный паритет с FL Studio не обещается.

Срез 01: компилируемое окно, транспортная панель без аудио, понятные границы прототипа,
smoke и unit-тесты, лицензионная матрица, архитектура и три направления дизайна.
Приёмка: Debug/Release, оба CTest, открытие реального окна и снимок его содержимого.

Будущая приёмка MVP: deterministic render, round-trip и повреждённые файлы, transport/loop boundary,
реальное аудиоустройство без щелчков, экспорт WAV с проверкой заголовка/PCM/пика,
resize/DPI 100/125/150/200%, работа мышью и клавиатурой, предупреждение при закрытии несохранённого проекта.

До выпуска: выбрать совместимую лицензию, завершить тестирование и подготовить дистрибутив.
Текущий бренд OpenDAW — рабочий, проверка товарного знака не проводилась.
