# Три направления интерфейса

Метод: встроенный image_gen, ui-mockup, отдельный запрос на каждое направление.
Все изображения — концепты будущего UI; они не подтверждают реализованные функции.
Рабочий прототип отрисовывается компонентами JUCE, изображения не используются как его фон.

1. **A / Graphite / Mint** — спокойная точность, графит, мята и сиреневые паттерны.
2. **B / Ultraviolet / Ice** — выразительный студийный характер, чернильные поверхности,
   лавандовые клипы, ледяные метры, строгая геометрия и мягкий свет.
3. **C / Ember / Sand** — тёплая инструментальная эстетика, угольный коричневый, песок,
   янтарные акценты и спокойный шалфей; без деревянных текстур и тяжёлого skeuomorphism.

Размер запроса: 1536×1024 landscape. Тексты: OpenDAW, Arrangement, Piano roll, Mixer,
BPM 124. Вид целого окна без устройства; browser, transport, arrangement, piano roll, mixer.
Требования: оригинальная композиция, читаемость, тонкие правила, авторские icons,
нет копирования FL Studio и сторонних логотипов. Пополненные demo clips служат оценке плотности.

Все три изображения сгенерированы: docs/concepts/concept-a.png, concept-b.png, concept-c.png.
Полные фактические запросы сохранены рядом в prompts.txt.
Владелец выбрал C / Ember / Sand 2026-10-18. Тема, волновой знак и транспорт перенесены в native shell.
Логотип, splash и asset packs сейчас не нужны: собственный знак рисуется JUCE.
