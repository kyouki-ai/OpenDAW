# Сайт OpenDAW

Статический сайт без зависимостей и сборки. `dist/` содержит готовые HTML, CSS,
JavaScript и собственные media assets. GitHub Pages получает `dist/` из workflow
`Website` после успешных проверок при изменениях в main.

Локальная проверка: `node website/server.mjs`, затем адрес из вывода сервера.
Сервер слушает только localhost. `/__qa/mobile` открывает страницу в iframe
с viewport 390×844 для проверки media queries; это не тест физического телефона.
Проверки без браузера: `node website/check.mjs` — ссылки на assets/anchors,
целостность native PNG/WAV и синтаксис JavaScript.

Интерактивный веб-секвенсор использует Web Audio и запускается только по нажатию.
Пауза, уход со страницы и скрытие вкладки прекращают звук. Настоящее демо After hours
экспортировано приложением OpenDAW и приведено к mono PCM16 для страницы.
Снимки интерфейса получены из работающего приложения; никаких выдуманных отзывов,
числа пользователей, готового установщика или неподдерживаемых функций на сайте нет.

Переключение реальных редакторов использует View Transitions при поддержке браузером.
Scroll-reveal не меняет прокрутку; `prefers-reduced-motion` отключает декоративное движение.
Кнопки шагов управляются с клавиатуры; вкладки поддерживают стрелки/Home/End.
Сайт не использует внешние шрифты, аналитику, аккаунты и сетевые API.
